# N5.2 — Environment template

Short note for the production env template. Compose runbook remains `docs/ops/n5.1-prod-compose.md`.

## Source of truth

| Artifact | Role |
|----------|------|
| `.env.example` | Documented keys for local + **PRODUCTION** section |
| `ProductionSecurityValidator` | Fail-fast prod rules for JWT / encryption / CORS |
| `docker/docker-compose.prod.yml` | Requires DB + validator secrets at compose/runtime |

## Production required (must set)

| Variable | Rule |
|----------|------|
| `JWT_SECRET` | ≥ 32 chars; **not** the local/dev default |
| `CREDENTIALS_ENCRYPTION_KEY` | ≥ 32 chars; **≠** `JWT_SECRET` |
| `CORS_ALLOWED_ORIGINS` | Explicit list; no `*` |
| `DB_NAME` / `DB_USERNAME` / `DB_PASSWORD` | Required by prod compose |

Prod overlay also forces `SPRING_PROFILES_ACTIVE=prod`, `OPENAPI_PUBLIC=false`, `OP_ALLOW_ENV_API_KEY_FALLBACK=false`.

## Not secrets in git

Copy `.env.example` → a private `prod.env` (or similar). Fill secrets locally. Never commit `prod.env`.
