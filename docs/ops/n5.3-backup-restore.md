# N5.3 — Backup & restore

Scripts and runbook for operator backups. Full customer handoff index comes later (N5.6).

## Scripts

| Script | Purpose |
|--------|---------|
| `./scripts/backup-postgres.sh` | Dump Postgres + report files → `./data/backups/<UTC>/` |
| `./scripts/restore-postgres.sh <dir>` | Restore dump (+ reports). **Destructive.** |

Details: `docs/ops/runbooks/RB-006-restore-from-backup.md`

## Local report path

When running the backend via `./scripts/run-backend.sh`, reports land under `backend/data/reports`.  
Backup/restore defaults (from repo root) use `REPORT_STORAGE_PATH=./backend/data/reports`.  
Docker Compose uses `/data/reports` inside the container.
